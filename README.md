# Movies-Case-Study
This repository contains SQL scripts for a database of movies, users, and ratings.

**Contents**

_Movies_CreateDB.sql:_

Contains queries to create the database.

Creates the tables Movies, Users, and Ratings with all necessary columns.

Includes sample queries to insert data into the tables.

_Movies_Queries.sql:_

Contains 10 SQL query exercises based on the database tables.

**Usage**

First, execute Movies_CreateDB.sql to create the database and tables, and to insert sample data.

Then, run the queries from Movies_Queries.sql to practice the 10 exercises.

All queries are written using MySQL syntax but can be adapted to other SQL databases with minor adjustments.
